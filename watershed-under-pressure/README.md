# Watershed Under Pressure

A dependency-free Earth Science design challenge. Students vary rainfall, impervious cover, slope, and soil; observe animated runoff; inspect a hydrograph; and invest a 100-credit budget in mitigation projects. Trial data and a recommendation can be downloaded as a local text file.

Outputs are classroom indices, not site-specific flood forecasts. The app sends and stores no student information.

Run `node tests/model.test.js` from this folder. Open `index.html` directly or serve the repository as a static site.
