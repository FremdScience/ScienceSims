# Matter Under Pressure

A dependency-free Physical Science particle lab. Students predict and test the phase of water, ethanol, and oxygen across temperature and pressure conditions while comparing particle, observable, numerical, and phase-map representations. Trial data can be downloaded as CSV.

Phase boundaries are simplified for classroom sensemaking and exclude unusual high-pressure phases. The app sends and stores no student information.

Run `node tests/model.test.js` from this folder. Open `index.html` directly or serve the repository as a static site.
