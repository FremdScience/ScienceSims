# Blackout! Circuit Repair

A dependency-free Physical Science troubleshooting game. Students drag or keyboard-select components, use a virtual multimeter, diagnose open and short circuits, and complete three repair missions with responsive hints.

This is a simplified low-voltage model. The page explicitly warns students not to work with outlets or building wiring. It sends and stores no student information.

Run `node tests/model.test.js` from this folder. Open `index.html` directly or serve the repository as a static site.
