# Plate Boundary Expedition

A dependency-free 3D evidence game for Earth Science. Students rotate a projected globe, reveal data layers, collect evidence, classify convergent/divergent/transform boundaries, and choose a supported hazard response across three missions.

The world and evidence locations are intentionally stylized. The app makes broad plate-boundary patterns visible and does not predict real hazards. It sends and stores no student information.

Run `node tests/model.test.js` from this folder. Open `index.html` directly or serve the repository as a static site.
